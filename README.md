### 🚀 Featured Project

**[KOS — Knowledge Operating System](https://github.com/kayametehan/KOS)**

![Stars](https://img.shields.io/github/stars/kayametehan/KOS?style=flat-square&color=8B0000) ![Last Commit](https://img.shields.io/github/last-commit/kayametehan/KOS?style=flat-square&color=8B0000) ![License](https://img.shields.io/github/license/kayametehan/KOS?style=flat-square&color=8B0000)

Local-first knowledge base that turns documents, code, and web pages into an interactive knowledge graph — explore it visually or query it with Claude. Zero cloud dependency.

`Python` `SQLite FTS5` `D3.js` `FastAPI` `MCP Server`

- Hybrid search — BM25 + vector similarity with reciprocal rank fusion
- Auto-built knowledge graph with community/topic clustering
- Interactive graph explorer + offline HTML snapshots
- `kos ask` — query your knowledge base with Claude
- Built-in MCP server — 12 tools for Claude Desktop
