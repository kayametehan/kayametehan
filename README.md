## 👋 About Me

Kocaeli Anadolu Lisesi mezunuyum ve **Eylül 2026**'da İtalya'da **Messina Üniversitesi**'nde Data Informatics (Veri Bilişimi) eğitimime başlayacağım (kabul alındı, vize süreci devam ediyor). Üniversite öncesinde iki firmada yazılım ve teknoloji süreçlerinin tamamından fiilen sorumlu oldum. Yapay zeka, web geliştirme ve tasarım alanlarında kendi kendime öğrenerek ilerledim; **Teknofest** ve **TÜBİTAK** gibi ulusal yarışmalarda somut projelerle yer aldım.

> 🎯 **Hedef:** Data Informatics eğitimimi yazılım ve yapay zeka alanındaki pratik iş deneyimimle birleştirerek, yenilikçi ve gerçek dünya problemlerini çözen ürünler geliştiren bir yazılım/veri mühendisi olmak.

<p><strong>Index anything. Visualize everything. Ask Claude.</strong></p>
<p>Local-first knowledge base that turns your documents, code, and web pages into an interactive knowledge graph — then lets you explore it visually or query it with AI. Zero cloud dependency, zero data leaving your machine.</p>

<p>
<img src="https://img.shields.io/badge/Python_3.11+-ff0000?style=flat-square&logo=python&logoColor=white&labelColor=000000"/>

<img src="https://img.shields.io/badge/MCP_Server-ff0000?style=flat-square&logo=anthropic&logoColor=white&labelColor=000000"/>
</p>

</div>

```
kos index ./docs && kos ui        # interactive graph explorer
kos index ./docs && kos snapshot  # shareable standalone HTML
kos ask "how does auth work?"     # Claude answers from your docs
```

<table width="100%">
<tr>
<td width="50%" valign="top">

**✨ Highlights**
- 🔍 Hybrid search — BM25 + vector similarity with reciprocal rank fusion
- 🕸️ Auto-built knowledge graph with community/topic clustering
- 🖥️ Interactive graph explorer + offline HTML snapshots
- 🤖 `kos ask` — query your knowledge base with Claude
- 🔌 Built-in MCP server — 12 tools for Claude Desktop

</td>
<td width="50%" valign="top">

**⚡ Performance**
| Metric | Value |
|---|---|
| Cold startup | ~5 ms |
| Search latency | ~0.04 ms |
| Indexing | ~2,000 files/s |
| Idle RAM | ~23 MB |
| Test suite | 97 tests, 0.4s |
